# Functional Requirement

> **Dokumen:** Functional Requirement (FR)
> **Status:** Final
> **Tujuan:** Mendefinisikan kebutuhan fungsional sistem berdasarkan aktor dan domain fitur yang telah ditentukan.

| No.       | Aktor     | Functional Requirement             | Domain   | Deskripsi                                                                                           |
| --------- | --------- | ---------------------------------- | -------- | --------------------------------------------------------------------------------------------------- |
| **FR-1**  | Mahasiswa | Login                              | Pengguna | Mahasiswa login menggunakan NIM dan password yang terdaftar.                                        |
| **FR-2**  | Mahasiswa | Logout                             | Pengguna | Mahasiswa keluar dari sistem.                                                                       |
| **FR-3**  | Mahasiswa | Melihat Jadwal Kuliah              | Jadwal   | Mahasiswa melihat jadwal perkuliahan pada kurikulum program studi mahasiswa.                        |
| **FR-4**  | Mahasiswa | Melihat Daftar Materi Pembelajaran | Materi   | Mahasiswa melihat daftar materi pembelajaran pada mata kuliah di kurikulum program studi mahasiswa. |
| **FR-5**  | Mahasiswa | Melihat Detail Materi Pembelajaran | Materi   | Mahasiswa melihat detail materi pembelajaran pada mata kuliah di kurikulum program studi mahasiswa. |
| **FR-6**  | Dosen     | Login                              | Pengguna | Dosen login menggunakan akun yang terdaftar.                                                        |
| **FR-7**  | Dosen     | Logout                             | Pengguna | Dosen keluar dari sistem.                                                                           |
| **FR-8**  | Dosen     | Melihat Jadwal Mengajar            | Jadwal   | Dosen melihat jadwal perkuliahan dari mata kuliah yang diampu.                                      |
| **FR-9**  | Dosen     | Melihat Daftar Materi Pembelajaran | Materi   | Dosen melihat daftar materi pembelajaran pada mata kuliah yang diampu.                              |
| **FR-10** | Dosen     | Melihat Detail Materi Pembelajaran | Materi   | Dosen melihat detail materi pembelajaran pada mata kuliah yang diampu.                              |
| **FR-11** | Dosen     | Menambahkan Materi Pembelajaran    | Materi   | Dosen menambahkan materi pembelajaran pada mata kuliah yang diampu.                                 |
| **FR-12** | Dosen     | Mengubah Materi Pembelajaran       | Materi   | Dosen mengubah materi pembelajaran pada mata kuliah yang diampu.                                    |
| **FR-13** | Dosen     | Menghapus Materi Pembelajaran      | Materi   | Dosen menghapus materi pembelajaran pada mata kuliah yang diampu.                                   |
| **FR-14** | Admin     | Login                              | Pengguna | Admin login menggunakan akun yang terdaftar.                                                        |
| **FR-15** | Admin     | Logout                             | Pengguna | Admin keluar dari sistem.                                                                           |
| **FR-16** | Admin     | Melihat Daftar Data Pengguna       | Pengguna | Admin melihat data pengguna mahasiswa dan dosen.                                                    |
| **FR-17** | Admin     | Menambahkan Pengguna               | Pengguna | Admin menambahkan data pengguna mahasiswa atau dosen ke dalam sistem.                               |
| **FR-18** | Admin     | Mengubah Data Pengguna             | Pengguna | Admin mengubah data pengguna mahasiswa atau dosen.                                                  |
| **FR-19** | Admin     | Menonaktifkan Pengguna             | Pengguna | Admin menonaktifkan akun pengguna mahasiswa atau dosen.                                             |
| **FR-20** | Admin     | Melihat Jadwal Perkuliahan         | Jadwal   | Admin melihat data jadwal perkuliahan.                                                              |
| **FR-21** | Admin     | Menambahkan Jadwal Perkuliahan     | Jadwal   | Admin menambahkan jadwal perkuliahan ke dalam sistem.                                               |
| **FR-22** | Admin     | Mengubah Jadwal Perkuliahan        | Jadwal   | Admin mengubah data jadwal perkuliahan.                                                             |
| **FR-23** | Admin     | Menghapus Jadwal Perkuliahan       | Jadwal   | Admin menghapus atau membatalkan jadwal perkuliahan sesuai aturan sistem.                           |
